# WebTuner

浏览器里的乐器调音器：用麦克风拾音，实时算出音高和偏差，按乐器显示对应的调音界面。目前支持古琴、扬琴。

## 运行

```
npm install
npm run dev      # http://localhost:5173
npm test
npm run build
```

麦克风只能在 HTTPS 或 `localhost` 下使用。用手机访问电脑上的 dev server（`http://局域网IP`）时浏览器会拒绝授权，需要部署到 HTTPS 或用隧道。

## 结构

- `src/core/`：与乐器无关。`pitch.ts` 是 YIN 音高检测，`tuner.ts` 管麦克风和检测循环，`smoother.ts` 去抖，`music.ts` 做音名、频率、音分换算。
- `src/instruments/`：每种乐器一个文件，提供检测参数（频率范围、窗口长度）和自己的界面，在 `main.ts` 里登记。
- `src/ui/meter.ts`：所有乐器共用的模拟表盘。

加一种乐器：新增 `src/instruments/xxx.ts` 实现 `Instrument`，加进 `main.ts` 的 `INSTRUMENTS`。

## 设计上要注意的点

- 检测范围按乐器收窄（`detector.minFreq/maxFreq`）。范围越窄，倍频误差越少，计算量也越小；新乐器要覆盖到它最低、最高音再留出调偏的余量。
- 关掉了浏览器的降噪、回声消除和自动增益，它们会改变乐器的声音。
- `AudioContext` 必须在点击事件里同步创建，iOS Safari 在授权弹窗之后创建的会一直处于挂起状态。这一条只在桌面 Chrome 上验证过，没有 iOS 真机验证。
- 扬琴界面优先显示"琴上有的最近的音"，而不是最近的半音，所以音偏得多时也能指到琴上真实存在的音位。点击音名可以锁定目标。

## 扬琴音位数据

`src/instruments/yangqin-layout.ts` 是按《402型扬琴C调音位图[基本音位]及弦位图》逐项抄录的，包括每个音位用几号琴弦（15#–25# 缠弦，26#–30# 钢弦）。`yangqin-layout.test.ts` 里有交叉校验：同音异位的音恰好是已知的 12 个，每组括号包含的行数与原图一致。改数据后先跑测试。

图上只用虚线接在 a³、g³ 行后面的 ♯a³、♯g³ 没有单独标弦号，按同一根弦处理（30#）。

## 已知限制

- 只有 C 调基本音位，没有其他调的音位。
- 没有用真实乐器验证过，检测精度的测试用的是合成音（0.5 音分以内）。
- 检测每帧约 2 ms（桌面），手机持续使用可能偏耗电，目前没有限制检测频率。
